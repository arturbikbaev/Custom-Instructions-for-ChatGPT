# Changelog

All notable changes to this project are documented in this file.

## [2.0.1] - 2026-09-12

### Fixed

- Updated the settings path to **Settings** → **Personalization**.
- Aligned section names with the current interface: **Custom Instructions** and **More About You**.
- Removed the remaining obsolete field labels.

## [2.0.0] - 2026-09-12

### Changed

- Reworked `Custom Instructions` around accuracy, critical evaluation, current-fact verification, sensible autonomy, appropriate tool use, and verifiable calculations.
- Replaced the detailed personal questionnaire with a compact, privacy-conscious `More About You` template.
- Added a note about optimization for modern agentic workflows, including GPT-5.6 Sol and GPT-6 Astra.
- Removed outdated model references and unsupported claims about context-window usage.

The repository did not use formal versioning before version 2.0.0.
